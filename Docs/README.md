# PathPilot --- Hackathon Project Documentation

This folder contains the working product and engineering documents.

## Documents

1.  `PRD.md` --- What problem we solve, for whom, scope, requirements
    and success criteria.
2.  `SRS.md` --- Detailed functional/non-functional software
    requirements.
3.  `ARCHITECTURE.md` --- System architecture, data flow, API boundaries
    and AI boundaries.
4.  `DESIGN.md` --- UI/UX screens, design rules and low-bandwidth
    requirements.
5.  `DEVELOPMENT.md` --- Repository structure, Git workflow, testing and
    development rules.
6.  `PHASES.md` --- Day-by-day implementation phases and integration
    gates.
7.  `DEVELOPERS.md` --- Four-developer ownership, file boundaries and
    merge-conflict prevention.

## Locked Technology Stack

-   Frontend: Next.js + TypeScript + Tailwind CSS
-   Backend: Node.js + Express.js + TypeScript
-   Database: MongoDB Atlas + Mongoose
-   AI: Claude API
-   Validation: Zod
-   Auth: JWT + bcrypt
-   Deployment: Vercel + Render
-   Containerization: Docker

## Product boundary

The implementation follows the problem statement closely:

> Help a self-directed learner determine what to learn next, in what
> order, and toward what realistic outcome.

The product is not positioned as a generic chatbot, course marketplace,
or employment guarantee system.
