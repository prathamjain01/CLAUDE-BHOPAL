GET /api/health

Check if the API is running and AI is available.

Response:

  "status": "ok",
  "service": "PathPilot API",
  "version": "1.0.0-mvp",
  "aiAvailable": true,
  "features": {
    "skillGPS": true,
    "learnBuildProveAdapt": true,
    "proofBasedNextMove": true
  }
}
GET /api/goals

List all available learning goals.

Response:

{
  "success": true,
  "data": [
    "Frontend Developer",
    "Backend Developer",
    "Fullstack Developer"
  ]
}

Get the skills required for a specific learning goal.

POST /api/next-move

Core Feature 1: Skill GPS - Calculate the next best skill to learn.

Request Body:

{
  "goal": "Frontend Developer",
  "currentSkills": ["html", "css"],
  "dailyMinutes": 60,
  "device": "laptop",
  "name": "Rahul"
}
FieldTypeRequiredDescription
goalstringYesLearning goal
currentSkillsstring[]NoSkills already known
dailyMinutesnumberNoMinutes per day (default: 60)
devicestringNo"mobile", "laptop", "both"
namestringNoLearner name

Response:

{
  "success": true,
  "data": {
    "skillGap": {
      "totalRequired": 6,
      "alreadyKnow": 2,
      "stillNeed": 4,
      "progressPercent": 33
    },
    "nextMove": {
      "skill": {
        "id": "javascript-fundamentals",
        "name": "JavaScript Fundamentals",
        "estimatedDays": 25
      },
      "whyThisSkill": "JavaScript is your next step...",
      "learningTip": "Practice 60 minutes daily..."
    },
    "resource": {
      "title": "JavaScript Algorithms - freeCodeCamp",
      "url": "https://www.freecodecamp.org/..."
    },
    "project": {
      "title": "Simple Calculator",
      "acceptanceCriteria": [...]
    }
  }
}
POST /api/learner/start

Start a new learning session. Returns a learnerId for tracking.

Request Body:

{
  "goal": "Frontend Developer",
  "currentSkills": ["html", "css"],
  "dailyMinutes": 60,
  "device": "laptop",
  "name": "Priya"
}

Response:

{
  "success": true,
  "message": "Learning session started!",
  "data": {
    "learnerId": "f6ae5932-7fb1-4288-b69b-106e538d6f88",
    "learnerState": { ... },
    "nextMove": { ... }
  }
}
Important: Save the learnerId for all subsequent API calls.
POST /api/learner/:id/checkpoint

Core Feature 2: Learn → Build → Prove → Adapt

Request Body:

{
  "status": "LEARNING",
  "stuckReason": "Optional - only for STUCK status"
}
StatusDescription
LEARNINGStarted learning from the resource
BUILDINGStarted building the mini project
STUCKNeeds help (requires stuckReason)
COMPLETEDProved the skill, ready for next

Example - STUCK (Get AI Help):

POST /api/learner/f6ae5932.../checkpoint
{
  "status": "STUCK",
  "stuckReason": "I don't understand event listeners"
}

Response:

{
  "success": true,
  "message": "It's okay to be stuck. Let me help.",
  "data": {
    "stuckHelp": {
      "explanation": "Let's break this down...",
      "simplifiedSteps": [
        "Take a 5-minute break",
        "Re-read the resource section",
        "Try one small thing first"
      ],
      "encouragement": "Every developer gets stuck!"
    }
  }
}

Example - COMPLETED:

POST /api/learner/f6ae5932.../checkpoint
{
  "status": "COMPLETED"
}

Response:

{
  "success": true,
  "message": "Great work! Ready for Git & GitHub?",
  "data": {
    "nextMove": { ... }
  }
}

Testing with cURL

# 1. Health check
curl http://localhost:5001/api/health

# 2. Get goals
curl http://localhost:5001/api/goals

# 3. Get next move
curl -X POST http://localhost:5001/api/next-move \
  -H "Content-Type: application/json" \
  -d '{"goal":"Frontend Developer","currentSkills":["html","css"]}'

# 4. Start session
curl -X POST http://localhost:5001/api/learner/start \
  -H "Content-Type: application/json" \
  -d '{"goal":"Frontend Developer","currentSkills":["html","css"],"name":"Test"}'

# 5. Update checkpoint (use learnerId from step 4)
curl -X POST http://localhost:5001/api/learner/LEARNER_ID/checkpoint \
  -H "Content-Type: application/json" \
  -d '{"status":"COMPLETED"}'
